视频号直播答疑助手 · Windows 第一版

这是源码启动包，需要安装官方 64 位 Python 3.13、3.12 或 3.11，并非免安装 EXE。

1. 把整个文件夹复制到 Windows 电脑，完整解压。
2. 如果没有 Python，先到 https://www.python.org/downloads/windows/ 安装，勾选 Add python.exe to PATH，保留 Tcl/Tk。
3. 双击 Start.bat，首次会自动安装本地文字识别组件。
4. 在“设置 DeepSeek”中填写你自己的 API Key，点击测试连接、应用设置。密钥不用发给开发者。
5. 打开视频号直播伴侣，点击“选择弹幕区域”，在截图中框选评论文字。
6. 把助手和提词窗口移到评论区域外，点击“开始监听”。第一帧旧弹幕会跳过，请发一条新问题测试。
7. AI 自动生成答案，当前答案会停留；读完点击“下一条”。

通过可见屏幕的本地文字识别读取评论；弹幕列表须保持可见。高密度滚屏可能漏读。
请检查直播预览，确保提词窗口没有被直播采集。
DeepSeek API 按用量收费；程序内密钥本次运行有效，关闭后需要重新输入。
本地核心、模拟接口和人工中文样张已检查；你的 Windows 电脑、真实视频号弹幕和真实 DeepSeek 连接还需现场联调。请先内部试播。

详细说明和故障处理见“使用说明.md”。
