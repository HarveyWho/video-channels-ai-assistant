本版已内置 Qwen3.5 2B + 4B 模型与 Ollama Windows x64 CPU 运行组件。

首次使用：
1. 下载 Windows.Offline.Setup.zip 和全部 Live.Answer.Assistant.Offline.7z.001、002、003……分卷到同一文件夹。
2. 全部解压 Setup ZIP，双击 Install Offline.cmd，自动校验并解压完整软件。
3. 打开模型连接，选择本地 Ollama 和 2B 或 4B，测试 / 预热后应用。

无需另装 Ollama、Python 或联网下载模型。建议16GB内存、至少20GB可用磁盘空间。GitHub 单文件上限2 GiB，因此必须下载全部分卷。只含 CPU 运行组件；软件及安装脚本未签名。

完整包使用独立本机服务，不替换系统已有 Ollama；关闭助手时退出自己启动的服务，切换时只保留一个模型在内存中。

发布前检查：核心与安装脚本测试、源码和打包 EXE 的 OCR / GUI 构造自检、两个内置模型真实回答、分卷完整性和最终安装流程。Surface 实机速度、回答质量及真实直播负载尚需测试。

可选的 Live.Answer.Assistant.Windows.zip 是旧用户轻量升级包，不含生成模型；首次使用请选完整离线分卷。源码也不含模型。
