视频号直播答疑助手 v0.3.0-rc1 完整离线包

1. 在 Releases 下载 Windows.Offline.Setup.zip 和全部 Offline.7z.001、002、003……分卷到同一个文件夹。
2. 全部解压 Setup ZIP，双击 Install Offline.cmd。工具自动检查分卷并解压，随后启动软件。
3. 以后直接运行解压出的 Live Answer Assistant.exe；旁边的 Models、Local Runtime、_internal 都要保留。
4. 模型连接选择本地 Ollama，再选 qwen3.5:2b 或 qwen3.5:4b，测试连接 / 预热，再应用设置。
5. 无需另装 Ollama、Python 或下载模型。本地模式不需要 DeepSeek 密钥。
6. 下载和解压建议预留至少20GB空间。仅 Windows x64；建议16GB内存或以上。
7. 打开视频号直播伴侣，选择可见弹幕区域，开始监听。手动输入问题也能测试。
8. 重复用同题测试时点“重读当前弹幕”；没有问题入队时看状态栏的识别、过滤、重复计数。
9. 记录2B和4B预热后的首字、完整回答耗时，并检查内容是否可靠。首次切换可能较慢。

轻量 ZIP 和 Code → Download ZIP 不包含模型，首次使用请下载完整离线包。
本地回答只在本机生成；主播仍需核对事实，程序没有联网搜索。
